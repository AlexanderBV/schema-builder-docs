# Laravel SchemaBuilder - Documentación Oficial ⚡

Sitio de documentación interactivo construido con [VitePress](https://vitepress.dev/) para el paquete `warrior/schema-builder`.

## 🚀 Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run docs:dev

# Compilar para producción
npm run docs:build

# Previsualizar build de producción
npm run docs:preview
```
